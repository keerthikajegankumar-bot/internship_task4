# Task 4 - Logistic Regression

## Objective
Build a binary classification model using Logistic Regression.

## Dataset
Breast Cancer Wisconsin Dataset

## Tools Used
- Python
- Pandas
- Scikit-Learn
- Matplotlib
- Seaborn

## Steps Performed
1. Loaded dataset
2. Removed unnecessary columns
3. Converted target labels to numerical values
4. Split data into train and test sets
5. Standardized features
6. Trained Logistic Regression model
7. Evaluated using Accuracy, Precision, Recall, ROC-AUC
8. Visualized Confusion Matrix and ROC Curve

## Outcome
Successfully built and evaluated a binary classification model for breast cancer diagnosis.
